## 📋 Sobre

**Nextcent** é uma landing page com design minimalista, desenvolvida como projeto de estudo e prática de front-end moderno. O foco está em clareza visual, boa hierarquia tipográfica e componentização limpa com React.

## ⚙️ Como rodar localmente

### Pré-requisitos

- [Node.js](https://nodejs.org/) v18+
- npm ou yarn

### Instalação

```bash
# Clone o repositório
git clone https://github.com/DocCaio/Nextcent.git

# Entre na pasta
cd Nextcent

# Instale as dependências
npm install
```

### Scripts disponíveis

```bash
# Inicia o servidor de desenvolvimento
npm run dev

# Gera o build de produção
npm run build

# Pré-visualiza o build de produção
npm run preview

# Executa o linter
npm run lint
```

A aplicação estará disponível em `http://localhost:5173`.
